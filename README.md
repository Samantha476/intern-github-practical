# Intern Task Manager

A small web project used for **Practical 01 — GitHub & VS Code: Git Integration,
Version Control and Self-Study Example Project**.

## Files

- `index.html` — page structure
- `style.css` — styling
- `script.js` — task logic

## Run locally

Open `index.html` in a browser, or use the local XAMPP server:

```
http://localhost/github/intern-task-manager/
```
